# Codice da Guilda

O projeto é um programa de terminal em Python que registra heróis de uma guilda, para depois organizá-los em classe e em nível.
Uma das características do projeto (Ato 1) é que os dados não são fixos, eles somem depois de fechar o programa (a modificar no Ato 2).
Ele funciona através de 6 funções onde:


- cadastrar_heroi() = Cadastrar os heróis;
- listar_herois() = Ele lista todos os heróis que estão no baú daquela sessão. O baú acumula enquanto o programa roda;
- buscar_heroi() = Busca um herói escolhido pelo usuário e mostra o seu nome;
- filtrar_herois_por_classe() = Busca uma classe escolhida pelo usuário e mostra os heróis que tem essa classe;
- mostrar_numeros() = Mostra quantos são, a média de nível e o herói mais forte.
- menu() = Serve como o inicio de um portal, é algo que vai direcionar o usuário para cada função que ele quiser executar, é como um capitão que comanda tudo;

## Como rodar

- Python instalado (só isso — sem dependências).
- No terminal, dentro da pasta do projeto:

```bash
python codice.py
```


Obs: eu escolhi fazer o repositório em português porque todo o programa está nessa língua.
